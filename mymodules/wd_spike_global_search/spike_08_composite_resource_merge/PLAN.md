## 2. 验证问题

验证复合资源“订单”（`sale.order` + `purchase.order`）的：

1. 标题字段统一映射；
2. Business Date 统一映射；
3. 状态统一映射；
4. Snapshot 字段统一；
5. 默认排序；
6. Technical Model 优先级唯一性；
7. 空 Business Date 排序；
8. 同分稳定性；
9. Result Identity 去重计数；
10. “全部”计数。

## 4. 测试规模

- `sale.order`：100,000 条内存基准记录；
- `purchase.order`：100,000 条内存基准记录；
- 固定种子：`20261008`；
- 真实 Odoo 模型字段通过 ORM 元数据校验；
- 不向共享数据库写入 200,000 条业务记录。

## 5. 成功标准

| 项目 | 成功标准 |
|---|---|
| 映射 | 两个模型均能映射到统一标题、日期、状态、Snapshot |
| 排序 | 完全符合 BR-003.1 |
| 优先级 | 重复优先级被拒绝 |
| 空日期 | 排在所有非空日期之后 |
| 稳定性 | 同输入同排序 |
| 计数 | Identity 去重正确，全部计数等于分类去重后之和 |
