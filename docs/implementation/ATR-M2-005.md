## 4. 安全与数据边界

- 测试仅使用合成 `res.partner`、虚构字段字典和合成 `.xlsx`；没有把真实客户数据或模板送往 Provider。
- 编排代码在安全字段基线/数据政策缺失时默认拒绝 Provider 调用。单测仅在测试进程临时设置合成字段批准；UI M1 渲染验证临时进程只允许合成 `res.partner.name`，未调用 Provider，验证后已恢复普通服务。
- Provider SDK 使用 `llm.model.chat` Mock；本轮没有 API Token、Prompt/Completion 或业务字段值的外部传输。
- 变更未超出 CC 的 `office_engine_m2` 白名单，没有 `sudo()` 或业务身份切换新增路径。
