# TV-16：PDA 复核的宽松校验

## 验证结论

**可行。复核应将异常记录为复核事实，而不是套用盲盘阶段的阻断规则。**

## 规则

复核阶段：

- 货位不一致：阻断；
- 托盘不存在：不阻断，记录异常；
- 产品不存在：不阻断，记录异常；
- Serial 匹配不到：不阻断，记录异常；
- 数量不匹配：不阻断，记录异常；
- 复核明细不得修改盲盘明细。

建议复核明细使用：

```text
matched
not_matched
out_of_scope
not_in_blind
```

每条异常应保存输入文本、异常类型、复核人、时间和来源复核单。

## 结论生成

复核完成后由后端根据复核事实生成 `passed`、`failed` 或 `uncertain`。前端只能提交观察结果，不能直接伪造结论。

## 对 SRS 的影响

SRS R31-R38 和 AC42-AC50 已覆盖主要要求。TDD 应明确“异常不阻断”和“货位不一致阻断”的分界。
