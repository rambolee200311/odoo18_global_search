# TV-19：盲盘单状态机和重盘

## 验证结论

**可行。Recount 必须创建新盲盘单，不能把历史盲盘单退回 counting。**

## 状态

```text
draft → counting → done
   ↘             ↘
       cancel
```

主管审核状态可以作为独立字段或独立处理单状态，不应破坏盲盘事实冻结。

## Recount

执行重盘时：

1. 校验来源盲盘单为 `done`；
2. 校验主管允许重盘；
3. 计算同一工作包和货位的下一轮次；
4. 创建新盲盘单；
5. 将原盲盘单标记为被替代；
6. 原盲盘单及明细保持只读。

轮次和“一货位一轮一单”需要数据库或并发安全约束，不能只依赖 Python 查询。

## 对 SRS 的影响

SRS F1.5、F1.9、AC51-AC55 已覆盖；TDD 应明确 Recount 的事务边界、轮次并发和历史只读策略。
