# TV-12：lot_name 状态下识别产品码

## 验证结论

**可行，但产品条码查询必须由后端限定在当前工作包范围内，前端缓存只能作为性能优化。**

## 识别算法

```text
扫描输入 X
    ↓
按当前工作包允许的产品条码查询
    ↓
查到且属于范围 → 产品码，切换产品
查到但超范围 → 阻断
查不到 → lot_name
```

不能按条码长度、前缀或格式猜测输入类型。

## 缓存建议

可以在当前 PDA 会话中缓存：

```javascript
Map<barcode, {productId, workPackageId}>
```

缓存必须限定工作包，切换工作包时清空。缓存命中后仍需考虑工作包状态、产品范围和权限变化，后端最终校验不可省略。

产品条码和 Serial 冲突时，按 SRS 规则优先执行产品主数据查询；查到产品即作为产品码。

## 风险与 SRS 影响

- 每次查询数据库可能影响扫描延迟；
- 前端缓存过期不能导致越权；
- 缓存不能缓存 Serial 唯一性；
- 后端必须返回“超出范围”和“查不到”的不同结果。

SRS 规则 R9-R15 已足够；TDD 应定义产品条码查询 RPC、缓存范围和失效策略。
