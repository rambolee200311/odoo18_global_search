# TV-14：撤销上一条扫描

## 验证结论

**可行，但撤销必须通过后端业务方法完成，不能由前端直接删除记录。**

## 推荐设计

盲盘单维护最近有效扫描的顺序信息，例如明细创建序号或服务端时间加 ID。撤销动作：

```python
last_line = count.line_ids.search(
    [('state', '=', 'valid')],
    order='scan_sequence desc, id desc',
    limit=1,
)
last_line.action_undo_scan()
```

后端需要校验：

- 当前用户是否是盘点员；
- 盲盘单仍处于 `counting`；
- 明细是否属于当前盲盘单；
- 明细是否已被撤销；
- Serial 唯一性占用是否释放。

撤销后 Serial 可以重新扫描，但原始撤销事实是否保留，应通过状态或审计记录表达，不能物理删除以丢失追溯信息。

## 风险与 SRS 影响

- 多次撤销必须按有效扫描顺序处理；
- 并发点击需要幂等；
- 完成盲盘后不允许撤销；
- “只删除最近一条”与“保留审计记录”需要在 TDD 中统一定义。

SRS 无需改变；建议将撤销从“删除”明确为“作废最近一条有效明细并记录审计”。
