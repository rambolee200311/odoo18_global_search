# TV-20：一货位一轮一单约束

## 验证结论

**需要数据库级并发保证；单纯的 ORM `search()` + `create()` 不足。**

## 约束

业务键：

```text
work_package_id + location_id + round
```

如果要求只限制进行中的单据，应额外物化：

```text
round_uniqueness_active
```

然后对有效记录实施唯一策略。

## 并发处理

推荐流程：

1. 后端先做 ORM 查询，提供友好提示；
2. 数据库唯一策略作为最终保证；
3. 捕获唯一冲突并转换为明确的用户错误；
4. 冲突事务不得留下部分盲盘单或明细。

应用层锁和前端防重复点击不能作为最终保证。

## 轮次

创建 Recount 时不能使用简单的：

```python
max(round) + 1
```

因为两个并发请求可能计算出相同轮次。必须在数据库约束保护下重试，或使用受控锁记录。

## 对 SRS 的影响

SRS C33、F0.14、AC55 已明确业务规则。TDD 应补充：

- 唯一键；
- 有效状态定义；
- 并发冲突错误；
- Recount 轮次重试；
- 取消、替代和处理完成时如何释放约束占用。
