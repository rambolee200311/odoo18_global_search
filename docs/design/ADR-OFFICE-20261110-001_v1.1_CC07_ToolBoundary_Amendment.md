## Decision

Office Engine M2 Route B Agent 可见两个职责独立的既有工具：

- `odoo_record_retriever` 负责当前用户授权范围内的只读 ORM 查询，保持既有接口与 M1 兼容性。
- `office` 负责 Office 文件编辑及 Candidate、Accept、Reject、Finalize/Delivery。

Retriever 查询结果通过正常工具调用历史返回给 Agent；Office 不重复实现 ORM 访问，也不代理 Retriever。不得新增第三个公开 Office/Data 工具。

## 最小条款修订

- §ARCH-01：将“只公开一个 `office` Tool”改为“复用现有 `odoo_record_retriever` 和 `office` 两个工具；只允许这两个现有职责边界，不增加第三个公开工具”。
- §5 Tool Entry：移除 `office(action="retrieve")` 作为必须的数据读取路由；Retriever 独立调用，`office` 仅处理文件工作流。
- 架构图/流程图：数据读取流改为 Agent → `odoo_record_retriever` → Agent；编辑流改为 Agent → `office` → Provider/Validator/Version Service。

本 amendment 不批准任何真实 Provider 调用、真实数据外发、配置修改、服务重启、数据库升级或生产发布。测试期 dispatch 仍默认关闭，按 CC-M2-CB-07 授权门禁临时启用。
